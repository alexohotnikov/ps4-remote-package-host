# PS4 RPI Sender (для мака)

Локальная веб-морда для установки PKG на PS4 через **Remote Package Installer** (homebrew от Zer0xFF — отдельное приложение на консоли, не часть GoldHEN).

## Как это работает

```
мак (этот сервер)                     PS4
┌────────────────────────┐
│ веб-морда + HTTP-раздача│ ── JSON {"method":"activate","params":{"url":…}} ──▶ RPI (:9090)
│ PKG файлов (:8000)     │ ◀──────────────── PS4 сама качает PKG по HTTP ───────────
└────────────────────────┘
```

Мак не «передаёт» файл — он говорит PS4, откуда качать. PS4 скачивает PKG сама, напрямую с мака (или с любого URL — см. «Прямая ссылка»).

## Запуск

```bash
./start.sh ~/Downloads/ps4-pkgs            # папка с .pkg (по умолчанию ~/Downloads/ps4-pkgs)
./start.sh ~/Downloads/ps4-pkgs 8080       # другой порт (по умолчанию 8000)
```

`start.sh` держит мак бодрым через `caffeinate`, пока сервер работает, — отдельно запускать не нужно. Без скрипта: `node server.js <папка> [порт]`.

Открыть `http://localhost:8000` (адрес LAN-IP покажется в консоли при старте).

## Чек-лист перед установкой

1. PS4 и мак в **одной сети** (один Wi-Fi/роутер)
2. На PS4 включён HEN (GoldHEN), запущено приложение **Remote Package Installer** — оно должно висеть открытым
3. IP PS4: на консоли Настройки → Сеть → Просмотреть статус подключения
4. IP вписать в морде → «Проверить связь» → зелёная точка = RPI на связи
5. macOS спросит про входящие соединения для node → **Разрешить** (иначе PS4 не дотянет до файлов)
6. Запускай через `./start.sh` — он сам не даст маку уснуть во время закачки

## Возможности морды

- список .pkg из папки (обновляется кнопкой) → кнопка «→ PS4»
- «Прямая ссылка» — отправить PS4 любой URL в интернете, мак не участвует
- Advanced — отправить сырую JSON-команду (если версия RPI капризничает)
- лог событий от PS4

## Грабли

- **прогресс установки** виден на экране PS4 (в самом RPI), в морде — только подтверждение отправки
- если PS4 качает медленно — Wi-Fi; лучше мак в ethernet или оба в 5 ГГц
- имена файлов с пробелами/кириллицей — ок, URL кодируется
